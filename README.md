# Grindr X

Grindr X 安装包与版本更新说明。

本仓库仅用于分发 IPA 和发布更新说明，不包含应用源码。Grindr X 是独立客户端，与 Grindr 官方无隶属关系。

## 下载

请前往 [Releases](https://github.com/ch528/Grindr-X-Releases/releases) 查看已发布版本、更新内容及安装包。版本说明与安装包以 Releases 页面为准。

## 安装与更新

- 下载前请阅读对应版本的更新说明，确认设备与系统要求。
- 如安装包标注为未签名，需要使用自己的有效证书签名后安装。
- 下载 IPA 不会自动完成安装。覆盖更新时请保持原应用标识；更新前建议备份本地数据，避免卸载应用导致本地记录丢失。
- 本仓库不提供签名证书，也不保证第三方签名工具或证书的可用性。

## 版本说明

正式发布内容以 Releases 页面为准。测试版会单独标记，不能据此判断为正式更新。
